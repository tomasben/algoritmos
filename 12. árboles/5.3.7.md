## 5.3.7
Escribir una función recursiva que encuentre el número de nodos de un árbol binario.

```
Nodo = REGISTRO
  dato: entero
  ant, prox: puntero a Nodo
FIN_REGISTRO
  
SUBACCION sum(p: puntero a Nodo) ES
  SI (p = nil) ENTONCES
    sum := 0
  CONTRARIO
    sum := *p.dato + sum(*p.ant) + sum(*p.prox)
  FIN_SI
FIN_SUBACCION
```
